# TaxHarvest

A client-side Indian income tax calculator for salaried individuals for FY 2025–26 (AY 2026–27).

## Features

- Side-by-side tax computation under both Old and New Regimes
- Recommends the regime with lower tax payable
- Tax-saving tips based on unused deduction headroom
- Transparency in tax calculations by providing terms and methodology

## Pages

| File | Description |
|---|---|
| `index.html` | Home / About page |
| `pages/taxinput.html` | Tax calculator (income + deductions input, results table) |
| `pages/terms.html` | Terms, Methodology and disclaimer |
| `pages/profile.html` | User profile with name and avatar |

## Scope & Limitations

- Designed for **salaried resident individuals below 60 years of age**
- Does not cover senior citizens, NRIs, or self-employed individuals
- Capital gains, marginal relief, and TDS already paid are not accounted for
- For official filing, refer to [incometax.gov.in](https://www.incometax.gov.in)

## Disclaimer

This tool is for informational and planning purposes only. It is not a substitute for professional tax advice. Tax laws are subject to amendment — verify figures with a qualified Chartered Accountant before filing.
